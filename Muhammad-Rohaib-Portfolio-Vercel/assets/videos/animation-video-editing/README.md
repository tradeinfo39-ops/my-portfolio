# Replaceable video previews

- `motion-study-01.mp4` — sample kinetic typography clip used on `animation-video-portfolio.html`.
- `social-promo-01.mp4` — second sample motion clip.

Replace either MP4 with your own H.264 MP4 and keep the same filename to update the website player automatically. Keep the poster files in `assets/images/video/animation-video-editing/` or update the `poster` path in the page HTML.
