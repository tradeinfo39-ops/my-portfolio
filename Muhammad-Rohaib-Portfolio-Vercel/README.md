# Muhammad Rohaib — Portfolio

Premium light-theme, responsive, multi-page creative portfolio built with plain HTML, CSS and vanilla JavaScript.

## Deploy on Vercel

This is a static website. It does not require Node.js, a package install, or a build step.

1. Extract the ZIP file.
2. Open the extracted `Muhammad-Rohaib-Portfolio-Vercel` folder. **This folder itself is the project root**: `index.html`, `vercel.json`, `404.html`, and `assets/` are directly inside it.
3. Upload the contents of this folder to a GitHub repository (do not upload the ZIP file or an extra parent folder).
4. In Vercel, choose **Add New → Project** and import that GitHub repository.
5. Set **Framework Preset** to **Other** and **Root Directory** to `./`.
6. Leave **Build Command** and **Install Command** empty. Set **Output Directory** to `.` if Vercel asks; this is also set in `vercel.json`.
7. Click **Deploy**.

If you already created a Vercel project and get a 404, check that its Root Directory is the folder containing `index.html`, then redeploy.

## Local preview

Open `index.html` in a browser, or use the VS Code Live Server extension. Keep the folder structure intact. The standalone website previews and sample videos are stored locally in `assets/`.

## Replace your work

Keep the folder structure and existing filenames when replacing sample artwork or video files. Main image assets are under `assets/images/`; video files are under `assets/videos/animation-video-editing/`; interactive website previews are under `assets/previews/web/`.

The included logo, image, video and website samples are portfolio concepts, not client commissions. Replace them with your own completed work before presenting them as client projects.
